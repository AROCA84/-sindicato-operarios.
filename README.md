# PLATAFORMA SINDICAL — Agente técnico

Repositorio de trabajo para construir un agente técnico que ayude a terminar la web de PLATAFORMA SINDICAL y SINDICATO DE OPERARIOS, coordinando varios repositorios sin mezclarlos ni alterar producción sin autorización.

> Estado inicial: base de trabajo. No conecta todavía un modelo de IA ni ejecuta cambios autónomos. Las credenciales y el entorno de ejecución deben configurarse antes de habilitar esas funciones.
